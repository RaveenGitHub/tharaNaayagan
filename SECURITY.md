# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do NOT create a public issue. Instead, report it privately to the maintainers:

1. Draft an email describing the vulnerability, affected components, steps to reproduce, and potential impact.
2. Maintainers will acknowledge receipt within 48 hours and provide a timeline for remediation.
3. A security advisory and patch will be released upon validation.

Thank you for helping keep our software secure!
